# 业务-生产 工贸一体型企业 全流程管理系统

> 范围：线索 → 客户 → 产品 → 商机 → 报价 → 打样 → 订单 → 采购 → 生产 → 出运 → 结算
> 核心原则：客户/产品是主数据（全局唯一），商机/订单/下游都以"上游 ID"做硬关联，全链路可追溯。

---

## 一、整体业务流程图（端到端）

```mermaid
flowchart TD
    subgraph 获客层
        L[线索 Lead<br/>多渠道/平台收集] -->|需求确认| C[客户 Customer<br/>强制建档]
        L -->|需求确认| P[产品 Product<br/>强制建档]
    end

    subgraph 销售层
        C --> O[商机 Opportunity<br/>漏斗节点]
        P --> O
        O -->|赢单| Q[报价 Quotation<br/>多版本]
        O -->|并行| S[打样 Sample<br/>任务]
        Q -->|客户接受| OOK[报价接受]
        S -->|确认通过| SOK[打样通过]
    end

    subgraph 履约层
        OOK --> ORD[订单 Order / PI<br/>金额·交期锁定]
        SOK --> ORD
        O -->|赢单| ORD
        ORD --> PUR[采购 Purchase<br/>材料]
        ORD --> PRD[生产 Production<br/>工单]
        ORD --> SHIP[出运 Shipment<br/>物流/报关]
    end

    subgraph 财务层
        PUR --> SET[结算 Settlement<br/>收付款/对账]
        PRD --> SET
        SHIP --> SET
        SET --> DONE([完结/复盘])
    end

    L -.->|无效/丢单| KILL([终止])
    O -.->|丢单| KILL
```

**关键串联规则（上游 ID 硬关联）：**
- 商机 `.customerId` / `.productId`
- 报价 `.opportunityId`
- 打样 `.opportunityId` + `.productId`
- 订单 `.opportunityId`（赢单后由商机生成）
- 采购 / 生产 / 出运 `.orderId`
- 结算 `.orderId` 或 `.shipmentId`

## 四、建议落地顺序（避免一次性全做）

1. **商机做实**：补全金额/阶段/赢单概率，关联报价与打样入口
2. **报价模块**：表单 + 列表，挂 `opportunityId`，支持多版本
3. **打样模块**：任务卡片，挂 `opportunityId` + `productId`
4. **订单模块**：由"赢单商机"一键生成，锁定金额/交期
5. **采购 / 生产 / 出运 / 结算**：以订单为驱动源，逐层扩展

> 每一层复用已有 Customer / Product / Opportunity 主数据，不新建客户/产品表。
