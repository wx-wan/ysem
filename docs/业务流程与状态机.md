# 业务-生产 工贸一体型企业 全流程管理系统

> 范围：线索 → 客户 → 产品 → 商机 → 报价 → 设计 → 样品 → 订单 → 采购 → 生产 → 出运 → 结算
> 核心原则：客户/产品是主数据（全局唯一），商机/订单/下游都以"上游 ID"做硬关联，全链路可追溯。
> 最后更新：2026-08-28（对齐当前实现进度）

---

## 一、整体业务流程图（端到端）

```mermaid
flowchart TD
    subgraph 获客层
        L[线索 Lead<br/>多渠道/平台收集] -->|需求确认转商机| O[商机 Opportunity<br/>阶段由下游单据自动推导]
        L -->|强制建档| C[客户 Customer]
        L -->|强制建档| P[产品 Product]
    end

    subgraph 销售层
        C --> O
        P --> O
        O -->|赢单/转订单| Q[报价 Quotation<br/>多版本]
        O -->|并行| D[设计 Design<br/>占位/规划]
        O -->|并行| S[样品 Sample<br/>打样任务]
        Q -->|客户接受| ORD[订单 Order / PI]
        S -->|确认通过| ORD
        D -->|输出设计稿| S
    end

    subgraph 履约层
        O -->|赢单| ORD
        ORD --> PUR[采购 Purchase<br/>材料]
        ORD --> PRD[生产 Production<br/>工单]
        ORD --> SHIP[出运 Shipment<br/>物流/报关]
    end

    subgraph 财务层
        PUR --> SET[结算 Settlement<br/>收付款/对账]
        PRD --> SET
        SHIP --> SET
        SET --> DONE([完结/复盘])
    end

    L -.->|无效/丢单| KILL([终止])
    O -.->|丢单| KILL
```

**关键串联规则（上游 ID 硬关联）：**
- 商机 `.customerId` / `.productId` / `.leadId`
- 报价 `.opportunityId`
- 样品 `.opportunityId` + `.productId`
- 订单 `.opportunityId`（赢单后由商机生成）
- 采购 / 生产 / 出运 `.orderId`
- 结算 `.orderId` 或 `.shipmentId`

## 二、主对象生命周期状态机

### 2.1 商机 Opportunity（阶段派生，不落库）

> 阶段不再由前端手动维护，统一由关联的报价/订单单据推导（见 `server/src/utils/pipelineStage.ts`）。
> 优先级由后往前：越靠后代表推进得越远。

```mermaid
stateDiagram-v2
    [*] --> LEAD
    LEAD --> OPPORTUNITY : 线索确认转为商机(绑定 leadId)
    OPPORTUNITY --> QUOTED : 生成报价单
    OPPORTUNITY --> SAMPLE : 生成样品单
    QUOTED --> SAMPLE
    SAMPLE --> PRODUCTION : 生成生产单
    PRODUCTION --> SHIPPED : 生成出货单
    SHIPPED --> ORDER : 生成正式订单(PI)
    ORDER --> [*] : 完结

    note right of OPPORTUNITY
        阶段只读、自动推进
        不可手动修改
    end note
```

| 阶段 key | 含义 | 触发条件 |
|----------|------|----------|
| `LEAD` | 仅线索 | 尚未转为商机 |
| `OPPORTUNITY` | 商机 | 已绑定 leadId / 已建档 |
| `QUOTED` | 已报价 | 关联 ≥1 报价单 |
| `SAMPLE` | 已打样 | 关联 ≥1 样品单 |
| `PRODUCTION` | 已生产 | 关联 ≥1 生产单 |
| `SHIPPED` | 已出运 | 关联 ≥1 出货单 |
| `ORDER` | 已下单 | 关联 ≥1 正式订单 |

> 同一商机若关联多种单据，取最高阶（数值最大）阶段展示。
